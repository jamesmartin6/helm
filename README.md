# Helm

Simulated electronic throttle-by-wire control unit — embedded C/FreeRTOS
firmware, a software-in-the-loop fault-injection test harness, a FastAPI
telemetry backend, and a live React dashboard.

**Status: under active development.** See [progress.md](progress.md) for the
current build checklist and [docs/build-plan.md](docs/build-plan.md) for the
full design spec. This README will be replaced with the final project
writeup once the build is complete.
